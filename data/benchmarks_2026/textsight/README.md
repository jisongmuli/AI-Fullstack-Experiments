# AI text detection: a control set that does not flatter detectors

Built and published by **[TextSight](https://www.textsight.ai/)**, an AI detection company.
We sell detection software, which is exactly why we published the numbers that make this
category look bad — including a detector scoring **0% on Claude Opus 5 output**.

700 English passages for evaluating AI-text detectors, assembled September 2026. It exists
because most published detector accuracy is measured against test sets that make the task
easy, and the numbers fall apart when you fix that.

**700 passages:** 644 provably-human, 56 AI-generated. Every row carries its provenance.

## Why bother

We evaluated an open detector three times. Only the test set changed.

| Evaluation | AUC | Detection at ~1% false-positive rate |
|---|---:|---:|
| Human = pre-1940 literature; AI = 2026 GPT-4o, different genre | 0.9985 | 88.2% |
| Human = pre-2022 Wikipedia + academic papers; same AI set | 0.9935 | 88.2% |
| **Same human set; AI = five current models, genre-matched** | **0.6711** | **25.0%** |

The same model, same code, same metric — from near-perfect to barely better than a coin flip.
Two things caused it: a "human" class of Victorian novels that no modern writing resembles, and
an AI class that differed from the human class in *genre* as much as in authorship.

A stronger detector (`Oxidane/tmr-ai-text-detector`) scores **AUC 0.8670** and **50.0%
detection at ~1% false positives** on the honest test. Its misses are not evenly distributed:

| Text generated by | Caught at ~1% FPR |
|---|---:|
| Claude Haiku 4.5 | 92% |
| GPT-4.1 | 83% |
| gpt-oss-120b | 58% |
| **Claude Opus 5** | **0%** (0 of 12) |
| **Qwen 3.8** | **0%** (0 of 8) |

Frontier-model output was not detected at all.

## Contents

### Human passages (644) — provably human, all published before ChatGPT existed

| File | n | Source | Licence |
|---|---:|---|---|
| `data/human_wikipedia_pre2022.jsonl` | 155 | English Wikipedia revisions dated before 2022-01-01, 55 articles. Each row stores its **revision id and timestamp** | CC BY-SA 4.0 |
| `data/human_pmc_ccby_nonanglophone.jsonl` | 183 | PubMed Central open-access papers, 2015–2021, first-author affiliation in 12 non-Anglophone countries. Each row stores its **PMCID** and licence URL | CC BY 4.0 |
| `data/human_literature_publicdomain.jsonl` | 306 | Pre-1940 literature (Austen, Melville, Shelley, Doyle, Twain, Wilde, Fitzgerald, Ibsen…) | Public domain |

The literature split is included **as a negative control** — to reproduce the inflated number,
not because it is a good test set. Use the first two for real evaluation.

### AI passages (56) — `data/ai_generated_2026-09-29.jsonl`

Generated 2026-09-29 from five models: `claude-opus-5` (12), `claude-haiku-4-5` (12),
`gpt-4.1` (12), `gpt-oss-120b` (12), `qwen-3.8-27b` (8).

Written in the **same two genres as the human text** — encyclopedic reference prose and
biomedical academic prose — so that genre cannot separate the classes. **Every row stores the
exact prompt.** No model was asked to evade detection or to "write like a human"; paraphrased
and humanised text is a different problem and is not represented here.

### Scores and scripts

`scores/` holds per-passage probabilities from both evaluated models, so every number above is
recomputable without rerunning inference. `scripts/` holds the collectors and the scorer:
`build_wikipedia_pre2022.py`, `build_pmc_esl.py`, `build_ai_2026.mjs`, `score_file.mjs`.

## Row format

```json
{"id": "...", "label": "human" | "ai", "source": "...", "text": "...",
 "attribution": "...", "pmc_id": "...", "prompt": "...", "licence": "..."}
```

`label` is ground truth. Human rows carry `attribution` or `pmc_id`; AI rows carry `source`
(the generating model), `genre` and `prompt`.

## Limitations

- **Small.** 644 human and 56 AI passages. A threshold set at a 1% false-positive rate rests on
  roughly three passages and is correspondingly uncertain.
- **Two genres.** Encyclopedic and academic. Student essays, business writing and informal prose
  are absent — and student essays are the setting where false accusations actually happen.
- **The ESL proxy is weak.** Non-Anglophone affiliation on a *published* paper means the text was
  professionally copy-edited. Raw learner writing is not represented. It is not for lack of
  trying: Cambridge Write & Improve, LOCNESS, ICNALE and EFCAMDAT are all research-licence-only
  and forbid derived use in anything commercial, so none of them can inform a tool that ships.
- **No paraphrased or humanised AI text**, which is what defeats these models in practice.
- English only.

## Who made this and why

[TextSight](https://www.textsight.ai/) builds AI detection tools. We assembled this corpus to
answer an internal question — whether a detector small enough to run in a browser is good
enough to publish — and the answer was mostly no. We published the corpus and the negative
result rather than quietly picking a friendlier test set, because the alternative is what
produced the 99% accuracy claims all over this category.

A companion tool that runs the evaluated model in your browser:
