# 文档任务状态与 Agent 下载加固

## 修改

- 取消任务时，完成报告清理并释放处理名额后才发布结束状态。清理异常提供明确反馈，同时释放名额。
- 每次任务状态变化递增 `revision`。页面合并查询结果时保留较新版本，取消意图持续到任务结束，避免延迟响应让进度回退或重新启用按钮。
- 已结束任务支持“移除记录”，仅清除任务摘要；对应报告继续由报告列表管理。运行中的任务返回 409。
- 文档页面与 Agent 共用报告下载模块，处理过期报告、网络错误、重试和中文文件名。同一报告同一格式的同时下载共用一次传输。

## 新增接口

`DELETE /api/document/jobs/{job_id}` 移除结束任务的摘要，返回 `{"deleted": true}`；任务不存在返回 `false`；运行中返回 409。任务集合、单项查询与取消响应均提供 `revision`。
