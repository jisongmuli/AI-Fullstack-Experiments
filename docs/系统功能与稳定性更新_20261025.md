# 系统功能与稳定性更新（2026-10-25）

本轮完善本地工作台的请求处理、页面交互和临时报告管理。开发分支为 `codex/system-stability`，初始完整备份保存在 `codex/project-backup`。

## 已实现

1. 图像解码、推理与内容凭证检查转入工作线程。Agent 上传图片的解码也在工作线程完成，接口主循环可以继续响应健康检查和运行状态查询。
2. 分析与编辑接口统一限制为同时处理 2 项请求。检查发生在上传正文缓冲之前；名额满时返回 HTTP 503、`Retry-After: 2` 和中文提示。完成、输入错误和异常退出都会释放名额。
3. 新增 `GET /api/runtime`，返回当前任务数、处理上限、已结束请求数、繁忙拒绝数，以及临时报告的数量、字节数和容量。已结束请求数包含验证失败或执行失败的请求。页面左下角每 3 秒更新服务状态，隐藏页面暂停轮询，单次查询 4 秒超时。
4. 图像、文本、规则编辑和大模型预览增加提交保护。规则编辑与大模型预览共用一个处理状态。处理期间切换输入时，旧文本结果会替换为“输入已更新”提示；旧图片结果会被丢弃。按钮按当前输入恢复可用状态。
5. Agent 同时上传文档与图片时，先完成文档提取校验，再启动检测工具，损坏文档可以及时反馈。
6. 服务通过 FastAPI 生命周期管理临时报告缓存，退出时清空报告并取消过期定时器。运行状态接口仅返回聚合信息。
7. 完整流程检查脚本自动创建输出目录，方便直接指定新的验证记录位置。

## 本机使用

在项目根目录运行：

```powershell
.\scripts\server-control.ps1 -Action Start -Port 8002
```

打开 `http://127.0.0.1:8002/`。左下角显示“服务就绪”或当前处理数量；悬停可查看已结束请求数和暂存报告数量。并发满载时稍后重新提交。

运行验证：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s code/server/tests
.\.venv\Scripts\python.exe scripts/portable_smoke.py --url http://127.0.0.1:8002 --output results/stability_20261025/portable-smoke.json
.\.venv\Scripts\python.exe scripts/stability_smoke.py --output results/stability_20261025/concurrency.json
npx --yes --package @playwright/cli playwright-cli -s=aigc-stability open http://127.0.0.1:8002 --browser=chrome
npx --yes --package @playwright/cli playwright-cli -s=aigc-stability --json run-code --filename output/playwright/stability-check.js
```

并发检查需要先让服务空闲，单独执行。当前并发上限以单服务进程为单位，默认启动方式为一个 Uvicorn 进程。浏览器中的“取消等待”保留现有行为，后台分析完成后释放名额。临时报告保留最多 30 分钟，继续支持手动删除和导出。
