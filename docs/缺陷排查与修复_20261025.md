# 缺陷排查与修复（2026-10-25）

基于 `00ce043` 版本继续检查输入变化、异步图片选择、Agent 附件与编辑数值检查。本轮复现并修复 9 类问题，代码继续更新到 `codex/system-stability` 和原私有 PR。

## 修复项目

| 问题与触发方式 | 修复后的行为 |
| --- | --- |
| 候选改写将 `20%` 改成 `20`，或将 `-5` 改成 `5`，原数值检查仍通过 | 比较完整数值标记，包含正负号、小数、科学计数法指数和百分比等单位；发生变化时拦截候选。保留单位前空格及等价 Unicode 符号的兼容处理。 |
| 文本分析完成后修改输入，页面仍显示旧分数与旧高亮 | 输入变化立即清除旧结果，显示“输入已更新”，重新分析后展示当前文本的结果。 |
| 编辑完成后修改原文，旧建议和“放入原文框”按钮仍可使用 | 输入变化清除旧建议、原意比较和操作按钮，同时覆盖规则建议及大模型预览。 |
| 浏览器拒绝剪贴板写入，复制建议产生未捕获异常 | 捕获复制失败，在按钮上提示手动复制，保留建议正文供选择。 |
| Agent 先选择有效文档，再选择不支持的文件，仍保留上一份附件 | 清除先前附件和无效文件输入；空文件也在页面内及时拒绝。 |
| Agent 导入 6,000 个 emoji 时，被错误判为超过 10,000 字符 | 导入、页面计数与发送校验统一使用 Unicode 码点；10,000 字符边界可用。消息预览也按码点截断。 |
| 点击示例图片后手动上传新图，较晚完成的示例请求覆盖新图 | 为图片选择增加版本检查，手动上传、清除和再次选择示例都会使先前请求失效。 |
| 示例图片请求返回 404，页面仍显示“图片已就绪” | 检查 HTTP 状态，失败时显示中文提示并清空待分析图片。 |
| 清除图片后，文件信息栏设置了 `hidden` 仍显示 | 增加统一隐藏规则，避免布局样式覆盖隐藏状态。 |
