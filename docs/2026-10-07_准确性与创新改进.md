# 多模态检测准确性与来源证据改进（2026-10-07）

本文件记录实验一至五之后的增量工作，不修改原实验报告的历史结果。当前系统仍是课程与人工辅助原型，未达到真实平台自动审核的验收要求。

## 已实现的改进

1. **文本情境弃判。** 先识别明显的写作指令、Markdown 引用块和围栏代码块，再决定是否调用文本分类器。被识别为非待审成稿的片段不打分、不高亮，并保留原因。整篇可评分字符低于 80%、段落信号明显冲突或长度超出已评估范围时，整篇不给单一分数，只保留适用段落的实验性结果。英文模型额外提示既有外测标签污染，不能援引其准确率。
2. **凭证与像素模型双轨证据。** JPG/PNG 上传保留原始字节，调用 [官方 c2pa-python SDK](https://github.com/contentauth/c2pa-python) 本地核验内容凭证。接口只返回 `credential_absent`、`valid_but_untrusted`、`trusted`、`invalid` 等状态、已知操作/来源词汇和核验代码，不返回完整清单、提示词或私人 EXIF。关闭远程清单与 OCSP 查询，避免上传触发第三方网络请求。凭证状态不改变双图像模型的风险分数；无凭证不被解释为 AI 证据，可信凭证也不自动证明声明内容属实。
3. **Agent 证据并列展示。** 图像页与 Agent 页分别展示两项候选图像模型分数、模型分歧、C2PA 状态和文本段落证据。手机端改为完整页面滚动，长结果不再被局部滚动容器遮挡。页面不生成跨模态统一“AI 率”。

## 尚不能宣称的准确率

普通图片模型仍将来源结论固定为“无法可靠判断”。既有鞋图和艺术图的原始尺寸分别约 240×240、256×256，而在本记录形成时接口要求普通图短边至少 512 像素；这些离线结果不能视为当时接口的同域准确率。2026-10-11 起，短边 200–511 像素改为仅给探索性候选分数，仍不能把旧数据称为独立准确率验证，详见 [后续小图说明](2026-10-11_小图候选分数与局部敏感度.md)。已有 512 主题图的来源和尺寸差异存在混杂，且三个公开集已参与模型选择。尤其艺术图双模型探索性 AUC 仅 0.540，误报仍高。C2PA 核验改善的是**来源证据质量**，没有提高像素分类器的 AUC。

后续另从 [OwensLab CommunityForensics-Eval](https://huggingface.co/datasets/OwensLab/CommunityForensics-Eval) 固定行范围取得 Firefly Image2 生成图与 LAION 真实图各 50 张（原图短边至少 512 像素），统一中心裁剪并保存为 512×512、JPEG q90。这 100 张此前未参与本地选模或阈值设置；预训练重叠仍无法排除。在这个单一生成器小样本上，双模型均分 AUC 为 0.752，0.8 高分界线的误报率为 5/50、召回为 30/50；要求两个模型都高于 0.8 后误报仍为 5/50、召回降为 29/50。**一致性规则未提高此处误报表现，不能宣称准确率提升。** 数据集仅许可非商用研究与教学，测试结果只适用于保存的归一化 JPEG，不代表原生平台图片。见 `results/highres/communityforensics_firefly_holdout.json`；可运行 `python code/models/evaluate_communityforensics.py --offline-recompute` 离线核对样本哈希和分数。

文本段落高亮阈值为 0.99。页面中的高亮百分比是“高亮字符占已评分字符的比例”，**不是 AI 撰写比例**；现有中文数据只有整篇标签，没有逐段真值，也没有真实平台盲测。英文外部作文集的 1,045 条 AI 标签中，961 条实际上是写作指令，历史外测准确率不能作为 AI 成稿识别性能。任何模型分数都不能确定作者身份。

## 下一轮真正的准确率验收

图像方面应从有明确许可的目标平台收集原生 ≥512 像素摄影、绘画、截图、压缩图和多种生成器样本；先冻结模型、阈值和弃判规则，再由独立标注人员做盲测，分别报告各类误报率、漏报率、覆盖率及置信区间。不能把已经用于模型选择的公开集再次称为独立测试集。

文本混写边界可先用 [SemEval-2024 Task 8 官方 Subtask C](https://github.com/mbzuai-nlp/SemEval2024-task8)作为英文离线基准，按其原始**空格分词**边界标注报告词级 MAE；[论文](https://aclanthology.org/2024.semeval-1.279/)说明这是“人类前缀 + AI 续写”的单边界任务，不能外推中文或多处交错段落。最终仍需合法取得目标平台、逐段独立标注的盲测文本。真实平台上线指标目前没有可报告的实测值。

## 复现

```powershell
python -m pip install -r code/server/requirements.txt
python code/server/evaluate_provenance.py
python code/models/evaluate_text_policy_v2.py
python code/models/evaluate_communityforensics.py --offline-recompute
python -m unittest discover -s code/server/tests -q
python code/models/test_text_segments.py
python -m uvicorn app:app --app-dir code/server --host 127.0.0.1 --port 8002
```

浏览器打开 `http://127.0.0.1:8002/`。Agent 同时上传 JPG/PNG 与文本时，返回两种模态的独立结果；C2PA 与图像模型分数作为两条证据显示，不合成单一概率。
