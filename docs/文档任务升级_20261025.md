# 文档任务升级（2026-10-25）

文档检测升级为可查看进度的后台任务，保留现有同步接口、图文检测、Agent 和报告导出流程。

## 页面使用

1. 上传 DOCX、PDF、TXT、MD，或粘贴长文，点击“检测文档并标注”。页面显示提取、分析和报告生成阶段。
2. 点击“后台继续”可继续操作其他页面或提交另一份文档。后台任务完成后，报告出现在当前可用报告列表中。
3. 刷新页面后，在“文档任务”点击“查看进度”，可恢复正在运行的任务；完成的任务支持“查看报告”。正在运行的任务优先展示。
4. 点击“取消任务”会向服务发送取消请求。当前文件提取或模型调用完成后，任务在下一检查点停止；取消期间显示“正在取消”。取消完成后保留任务状态，清理本次尚未提交的报告。

分析进度按照实际处理的分析单元推进。短文通常由一次模型调用处理，长文按已有分段规则逐片段处理。阶段进度条展示工作完成情况。

## 运行与保留

- 后台任务与图像、文本及编辑接口共用默认 2 项处理容量。后台任务提交成功后继续占用名额，直到完成、取消或失败；健康、状态查询和取消接口保持可用。
- 原文和文件内容只在本机内存处理，完成后任务记录保留文件名、阶段、进度、报告编号或错误信息。
- 任务记录最多 20 条，优先移除已结束的旧记录。运行中的任务保留到结束；结束 30 分钟后过期，查询时清理。页面显示运行任务和最近结束任务，最多 8 条。
- 报告继续使用已有 30 分钟、20 份和 32 MiB 缓存限制，支持 Word、HTML 和 JSON 导出。
- 服务退出时先请求取消并等待文档工作线程结束，再清空报告缓存。
- 同步 `POST /api/document/detect` 和 Agent 文档接口继续可用，已有检测模型与评分规则保持当前版本。
- 修复长文件名被截断后丢失扩展名的问题，缩短展示名称时保留扩展名。

## 接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/document/jobs` | 上传 `file` 或表单 `text`，返回 202 和任务编号 |
| `GET /api/document/jobs` | 查询当前任务与最近结束任务的摘要 |
| `GET /api/document/jobs/{job_id}` | 查询状态、阶段进度、报告编号或错误 |
| `POST /api/document/jobs/{job_id}/cancel` | 请求取消；已结束任务保持原状态 |

任务状态为 `pending`、`running`、`cancel_requested`、`completed`、`cancelled` 或 `failed`。`stage` 区分提取、分析和保存；`completed/total` 记录分析单元完成量；`report_id` 在成功后提供。
