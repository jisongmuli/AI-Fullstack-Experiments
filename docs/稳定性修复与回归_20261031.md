## 已修复的问题

| 触发情形 | 原有表现 | 修复后的行为 |
| --- | --- | --- |
| 助手上传旧版 `.doc`、损坏 DOCX、空文件或空白文本 | 文档提取异常直接进入 500 | 使用文档服务原有的 415 / 422 / 400 等状态和中文说明；校验失败时不执行大模型，表单可以重新提交 |
| 对话记录的 `role` 被传为列表或对象 | 集合成员检查抛出类型错误 | 先检查类型，返回 400 校验说明 |
| 工具计划类型错误、工具列表嵌套或重复 | 部分计划引发 500 | 完整检查工具名称、类型、数量、去重与允许范围，返回可读说明并释放助手执行名额 |
| 一个工具返回非 JSON、列表 JSON 或发生内部异常 | 整个助手请求中断，其他工具结果丢失 | 将当前工具记录为失败，保留 HTTP 状态；后续工具继续执行并显示结果，内部异常内容不进入用户返回 |
| 课程文本含全角字母、兼容标点、连续空白或换行 | 推理预处理与训练数据不同，纯空白还可能补足长度门槛 | 数据准备和推理共用 NFKC 与空白规范化，基于规范化正文判断长度与中文范围 |
| 课程样例下载失败 | 错误信息替换五个实验卡片 | 错误显示在独立状态区域，保留实验记录；按钮恢复可用 |
| 样例请求尚未完成时，用户切换页面、修改输入或开始检测 | 迟到的样例可能覆盖新内容和模型选择 | 离开课程页取消请求；载入前后核对页面、输入、模型及检测状态；请求期间避免重复下载 |
