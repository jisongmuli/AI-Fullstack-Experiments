# 一 实验目的

本实验围绕“多模态AIGC内容检测与可信编辑系统”建设可追溯的数据基础。我们获取公开图像与英文文本，派生图像结构化元数据；核验来源和标签、检查质量、控制文本长度捷径、完成 8:1:1 划分与训练集增强，并用固定小模型比较处理效果。实验一只评价数据与教学基线，不上线检测服务，也不依据分类分数认定作者身份。

# 三 实验内容与步骤

## 3.1 需求分析与数据获取

项目最终面向图像检测、文本检测和可信编辑，但实验一仅建设前两项的数据基础。选择三类实际可处理的数据：CIFAKE 的非结构化图像、两个 Kaggle 英文文本集，以及由图像计算的亮度/对比度/文件大小等结构化 CSV。图像与文本来自不同样本，**不是图文对**；不虚构多模态配对关系。三份原包的来源说明、下载时间、平台许可字段、ZIP 文件 SHA-256 全部存入 `data/raw/*_source.json`。

| 来源 | 原始规模 | 用途 | 来源核验结果 |
| --- | ---: | --- | --- |
| CIFAKE | 120000 张 | 图像训练、验证、测试 | REAL/FAKE 各 60000；页面正文称 MIT 条件、平台字段为 Other，要求引用 CIFAR-10 和 CIFAKE |
| AI and Human Text Dataset | 6069 条 | 文本主数据 | Human 3000、AI 3069；平台字段 CC BY 4.0，实际 CSV 缺少网页宣称的逐条 `source` 列 |
| Human vs AI Generated Essays | 2750 条 | 独立外部测试 | 平台字段 CC0；页面总量为占位符 N，实际需按 CSV 核算，缺少逐条来源 |

公开页面与下载链接列在随附 README。处理后数据集目前只在本地 `AIGC实验1/data/`，没有虚构公网发布地址。

## 3.2 清洗、标准化与划分

图像：逐张解码并计算文件 SHA-256、RGB 像素 SHA-256、尺寸、亮度、对比度和文件大小。全量 120000 张中，1336 张与更早样本像素相同；其中跨源训练/测试重复 378 张、测试内部重复 38 张。排除后可用 118664 张。本实验从源训练池抽训练 4000、验证 800，从源测试池抽测试 800，三组各类均衡，所抽样本像素哈希交叉为 0。导出 32×32 RGB PNG，保留路径和源哈希清单。训练图像增强使用随机水平翻转和 ±8° 旋转，验证/测试图像不增强。

结构化元数据：`sample_id,relative_path,split,label,source_path,brightness,contrast,file_bytes,bytes_per_pixel`，其中 `bytes_per_pixel=file_bytes/(width×height)`。仅用训练集拟合 Min-Max 缩放器并保存最小/最大值，再对验证与测试做变换；这避免了把测试分布用于训练预处理。`bytes_per_pixel` 是文件压缩大小代理量，不能解释为视觉真实性证据。

文本：先做 HTML 实体解码、去 HTML 标签、Unicode NFKC 与空白规范化；映射 Human→0、AI→1；检查空值、非法标签、短文本与文本哈希重复。主集 6069 条在上述规则下无删除。审计发现原始人类文本字符中位数 1871，AI 文本仅 332，分类器很可能只学“长篇=人类”。因此从每条人类原文抽取连续片段，以 AI 样本词数分布设目标长度，并把完整原文与摘录位置保留在 CSV 清单。处理后人类/AI 字符中位数为 330/332，词数中位数均为 47。再按标签分层划分训练 4855、验证 607、测试 607；三组文本哈希交叉为 0。外部集先去掉 330 条精确重复，最终 2420 条，仅用于外部测试。

| 质量项目 | 清洗或控制前 | 后 |
| --- | ---: | ---: |
| 图像解码失败 | 0 | 0 |
| 图像像素重复的多余记录 | 1336 | 抽样集 0 |
| 抽样图像数量 | 120000 原包 | 5600 PNG |
| 主文本空值/非法标签/精确重复 | 0/0/0 | 0/0/0 |
| 主文本人类/AI 字符中位数 | 1871/332 | 330/332 |
| 外部文本精确重复的多余记录 | 330 | 0；余 2420 条 |
| 图像结构化表缺失单元格 | 不适用 | 0 |

长度匹配是数据策展，不是恢复原文真实生成条件。主集最短处理后片段为 23 字符，外部集人类/AI 字符中位数仍为 79/95；主题、模型与写作任务也未控制。

## 3.3 增强、基线和代码实现

图像使用同一三卷积小 CNN、Adam 学习率 0.001、batch 128、最多 3 轮，以验证集 macro F1 选轮次。唯一实验变量是训练图像是否执行翻转和小角度旋转。文本使用 TF-IDF（一元/二元词组、最多 20000 特征）和逻辑回归；增强版在 4855 条训练样本中选 599 条，每条只替换一个常见英文同义词，保留 `augmented_from` 溯源。改写后与原文平均句级 BLEU 为 0.9405，但高 BLEU 也不能证明每条语义无变化。验证、测试和外部集都不增强。

# 四 实验关键技术与难点

**长度捷径。** 原数据标签与文本长度高度关联。用 `log1p(字符数)` 作为唯一特征训练逻辑回归，原始同源测试准确率 99.84%；摘录匹配后下降到 50.74%。这说明长度捷径明显减弱，并不代表主题或来源捷径已经消失。保留原文和摘录起点使这种数据干预可审计。

**重复与泄漏。** CIFAKE 源包存在像素重复，不能直接按文件名分割。脚本先在全量源数据上做像素去重，保留原训练/测试池的边界，再抽样和划验证集。文本按规范化后哈希去重，确保本次同源三组无精确重复；未做语义近重复或同一作者聚类，因此仍存在未知泄漏风险。

**跨域、授权与隐私。** 两个文本集缺少逐条原作者和生成器；平台许可字段不足以证明每篇原文均可再分发。启发式隐私扫描在主/外部文本中发现 99/2 条疑似电话格式，邮箱格式均为 0；这些命中可能是日期等数字，尚未人工核验。5600 张处理后 PNG 的 EXIF 命中为 0。原包仅留本地，公开发布或商用前仍需核对权利链和个人信息；图像许可页的“Other”与正文 MIT 表述也需复核。

图像测试集只有 800 张，增强后准确率仅多 0.38 个百分点；人类图像被误报为 AI 的比例由 13.25% 增至 14.25%，不能只看准确率称其全面改进。文本同源测试增强后也仅多 0.33 个百分点，而外部测试仍只有 60.12%；外部集可能存在主题、长度和标签定义差异。一次固定随机种子的成绩没有置信区间，不足以证明增强具有稳定收益，更不代表系统可以判断一位作者是谁。

# 六 实验总结与展望

实验一完成了公开数据获取、12 万图像与两份文本的审计、标准化、分层划分、训练集增强及受控基线。关键发现是原文本存在“长度即标签”的捷径，文本跨来源准确率明显下降。后续应核验逐条来源，补充近重复和个人信息审计，开展多种子与跨来源评估。可信编辑模块要检查事实和原意保留；检测界面应允许“无法可靠判断”并由人复核。
