# 实验二与实验三：模型训练和算法优化

## 研究目标与数据边界

实验二在实验一固定的数据划分上分别训练图像和文本分类器，预测标签统一为 `0=真实/人类`、`1=AI 生成`。实验三对已经训练的模型做推理导出、词表压缩和“无法可靠判断”处理，比较准确率、体积与 CPU 单条延迟。图像与文本不是配对样本，两个分数也没有合并成所谓的多模态证据。

图像使用 CIFAKE 的 32×32 RGB 子集，训练 4000 张、验证 800 张、测试 800 张。文本使用长度匹配后的英文文本，训练原始 4855 条加实验一的同义词增强 599 条，验证 607 条、同源测试 607 条，另有不同公开来源的外部测试 2420 条。所有训练只看训练划分，模型及轮次通过验证划分选择。外部集只用于最终迁移能力检查。随机种子为 42，CPU 线程数为 4。

## 实验二：训练过程

图像模型是带批归一化和全局平均池化的五层卷积网络，共 140130 个参数。使用训练集随机水平翻转和小角度旋转、AdamW、交叉熵损失，训练 8 轮；按验证集 macro-F1 选择第 6 轮。它在测试集得到准确率 **89.75%**、macro-F1 **89.75%**、ROC-AUC **96.30%**；真实图像误判为 AI 的比例为 **12.00%**。混淆矩阵按真实/AI 行排列，为 `[[352, 48], [34, 366]]`。原实验一三层 CNN 增强探针测试准确率是 81.63%；两者架构、训练轮次均不同，这里仅作描述性参照，不能把差值解释为单一优化的因果收益。

文本模型比较了词级 1–2 gram、20000 特征与字符级 3–5 gram、30000 特征的 TF-IDF + 逻辑回归。验证集未经校准的 macro-F1 分别为 94.06% 和 97.69%，因此选择字符级模型，再对其做实验三压缩。部署的 10000 特征版本经验证集 sigmoid 校准后，同源测试准确率 **97.69%**、macro-F1 **97.69%**；外部测试准确率 **75.25%**、macro-F1 **73.63%**、ROC-AUC **85.09%**。外部混淆矩阵为 `[[1210, 165], [434, 611]]`，其中 434 条 AI 文本被判为人类。实验一增强文本探针外部测试为 60.12%，同样只是不同模型的描述性参照。

需要特别注意：同源测试接近 98% 并不意味着可判定任意文本来源。文本原始数据存在来源缺失和体裁差异；长度匹配只处理了已发现的一种混杂因素。模型校准用的是同源验证集，外部 Brier 分数从同源测试的 0.0144 升至 0.1833，说明概率在换来源后显著失准。

## 实验三：效率和不确定性

图像模型导出为 TorchScript，固定输入形状为 `1×3×32×32`。在本机 CPU、batch=1、预热 25 次、计时 200 次的模型计算测试中，eager 与 TorchScript 的 P50 分别为 **0.5915 ms**、**0.5516 ms**；导出文件却由 571026 B 增至 597526 B。测试图像上两种实现的最大 logit 差为 0。这个微小延迟差可能受机器负载影响，测量不含图片解码。

文本词表由 30000 缩至 10000 特征：验证集未经校准 macro-F1 从 97.69% 降至 97.36%，符合预设的下降不超过 1 个百分点的容差。压缩后文件由 **479938 B** 降至 **167326 B**（减少 65.14%）；单条文本推理 P50 从 **0.5679 ms** 至 **0.5506 ms**。给完整与压缩模型分别用相同验证集校准后，外部测试准确率分别为 **75.91%** 与 **75.25%**，压缩代价为 0.66 个百分点。外部数据没有参与压缩词表的选择，但这次外部比较不应再作为以后调参的独立测试结果。

系统使用固定分数区间：AI 类概率 `>=0.8` 显示“AI 风险较高”，`<=0.2` 显示“人类/真实类倾向”，中间显示“无法可靠判断”。这两个阈值是演示用保守边界，不保证对应真实世界 80% 的可信度。32×32 之外的图像、长度和语言超出本次训练范围的文本也强制返回 `uncertain`，即使同时展示分数。对图像测试集，阈值覆盖 81.88%，覆盖样本的准确率 95.27%；对外部文本，覆盖 72.31%，覆盖样本准确率只有 81.71%。因此仍不得据此直接断言作者身份、生成模型或造假事实。

## 可复现与交付

使用实验一同一 Python 环境，安装 `numpy, pandas, Pillow, scikit-learn, joblib, torch, torchvision`，在项目根目录运行：

```powershell
python code/models/train_and_optimize.py --root .
python code/models/compare_saved_text.py --root .
```

模型文件为 `models/image_detector.pt`（权重）、`models/image_detector.ts`（推理）、`models/text_detector_full.joblib`（实验二完整词表）、`models/text_detector.joblib`（实验三压缩部署）和 `models/model_config.json`（类别、阈值、校准参数）。具体环境版本、指标及基准测量保存在 `results/exp2_exp3/*.json`；验证、同源测试与外部测试的逐样本分数在同目录的 `*_predictions.csv`。不要加载不可信来源的 `.joblib` 文件。

后端在把 `code/models` 加入 Python 搜索路径后，可使用 `from inference import DetectorService`，然后调用 `DetectorService(project_root).predict_image(image_bytes)` 或 `.predict_text(text)`。返回 `risk_score`、`decision`、`signals`、`out_of_scope` 和 `limitations`。`signals` 中的字符片段是模型权重贡献，不是内容真伪的独立证据。

## 后续改进与责任边界

真正面向用户的系统还需要高分辨率、多生成器、多语言且有清晰授权的独立数据，做按来源分组的训练/验证/测试、概率再校准和人工复核评估。CIFAKE 仅有 32×32；当前外部文本结果明显弱于同源结果。可信编辑模块应关注具体表达问题与语义保真，不能以“去 AI 化”或规避检测为目标。
