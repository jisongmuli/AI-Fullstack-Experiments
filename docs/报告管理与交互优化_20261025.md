# 报告管理与交互优化（2026-10-25）

本轮打通报告生成、刷新恢复、导出和删除流程，并修正本机服务管理脚本的时间比较问题。代码继续保存在 `codex/system-stability`，更新同一个私有仓库 PR。

## 使用变化

- 文档页增加“当前可用报告”。上传检测和 Agent 文档分析生成的报告会自动加入列表，刷新页面后仍可恢复。列表显示文件名、检测时间、覆盖率和有效期，支持打开与单份删除。
- 打开文档页、返回该页面或手动点击“刷新列表”时更新列表。文档页可见时每 30 秒更新一次，离开页面或隐藏浏览器后暂停轮询。连接失败时保留已显示的条目，并提供刷新重试提示。
- 浏览器摘要记录收进单独的折叠区域，继续按用户勾选情况保存。服务内存中的报告最多保留 30 分钟、20 份，受 32 MiB 缓存上限约束。
- Word、HTML 和 JSON 导出先检查接口结果，再触发下载。过期报告、服务断开和导出错误在页面内反馈，中文下载文件名保持完整。
- 删除、恢复、分析和导出使用统一的页面处理状态。删除其他报告时继续显示当前报告；删除当前报告时清空当前结果，并更新列表与浏览器摘要。
- PowerShell 服务管理按 UTC 时间刻度比较实际进程与 PID 记录，兼容 JSON 时间字段被读取为字符串或 DateTime 两种情况，继续校验项目目录、进程、可执行文件、命令行和端口所有者。

## 接口

`GET /api/document/reports` 返回最新报告在前的列表，使用 `Cache-Control: no-store`。每项只包含报告编号、文件名、格式、创建时间、失效时间和高风险字符覆盖率。原文、分段详情和来源指纹通过具体报告接口读取。

## 重复检查

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s code/server/tests
.\.venv\Scripts\python.exe scripts/portable_smoke.py --url http://127.0.0.1:8002 --output results/reports_20261025/portable-smoke.json
.\.venv\Scripts\python.exe scripts/stability_smoke.py --output results/reports_20261025/concurrency.json
npx --yes --package @playwright/cli playwright-cli -s=aigc-stability open "http://127.0.0.1:8002/?v=reports20261025#document" --browser=chrome
npx --yes --package @playwright/cli playwright-cli -s=aigc-stability --json run-code --filename output/playwright/report-workflow-check.js
npx --yes --package @playwright/cli playwright-cli -s=aigc-stability --json run-code --filename output/playwright/stability-check.js
```

并发检查单独在服务空闲时运行。示例运行验证保持本机 CPU 模式和单服务进程，模型权重沿用已有版本。
