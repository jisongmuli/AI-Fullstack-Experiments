# 启动与图片预览优化 · 2026-10-26

本轮针对模型信息查询、按需加载和图片输入状态进行优化，基线提交为 `6ccf4a6`。项目位于 `E:\AIGC_latest_20261011`，本机入口为 http://127.0.0.1:8005/ 。

## 主要变化

- 模型信息页通过当前策略检查所需文件、分词器和完整权重大小。查询只读取少量配置，不导入机器学习依赖、不加载权重，也不扫描历史大模型。缺失分词文件和未恢复的 LFS 指针会给出具体路径。
- 图像与文本组件分别在首次检测时加载。图片检测无需读取文本词表；文本检测无需加载历史 CIFAKE 图像模型。并发请求只发布完整加载后的词表对，失败后可以重试。
- 当前 MPU 方案解除对候选 TASTE 分类头、策略和权重的运行依赖，候选文件继续保留用于对比复现。
- 已带模型版本的检测结果直接使用该版本，取消未被使用的历史权重哈希计算。旧模型返回未命名的有效结果时仍生成指纹版本。
- 图片成功解码后才开放“分析图片”。损坏图片会清除旧尺寸、预览和对象 URL；超过 2500 万像素的图片在上传前提示。4K、灰度、透明通道和小图继续受支持。
- 模型信息弹窗增加超时和请求版本控制，较早的延迟响应会被丢弃。

## 接口说明

`GET /api/models` 的 `available` 表示所需文件齐备，`loaded` 表示检测组件已经初始化。`artifact_fingerprints` 返回已存在的指纹缓存，`fingerprints_verified` 表示该缓存是否已有结果。完整包和公开数据的 SHA-256 校验由 `verify_package.py`、`scripts/verify_2026_assets.py` 执行。
