## 实验一：2026 年数据与划分

图片来自 NTIRE 2026 官方公开训练分片，固定 revision `b85af61d93cd4fd5e558b3ee69f6d93639fce83f`。通过受限 HTTP 字节范围读取 ZIP，校验单文件长度、CRC 与 SHA-256。抽取时排除上一轮审计的 264 个图片 ID；新图片按处理后 RGB 像素去重，400 张进入课程训练与评测，另外 20 张下载候选未进入划分。

图片训练 / 验证 / 测试分别为 **240 / 80 / 80**，每组两类均衡。保存原图、64×64 处理图及原始尺寸。通道均值与标准差只从训练集计算；随机水平翻转只应用于训练批次。来源、像素指纹与划分见 `data/course_20261027/images.json`。

文本来自 NLPCC 2026 官方训练文件，固定来源 revision `961a485fa72f9821d6315836d46c9d94818b18b1`，原文件 SHA-256 为 `d07059d8af0c7ba86629a8ceba3f09669d79f13356f09d0853861b53a8d5c01f`。使用人工原文 HWT 与生成文本 LGT，执行 Unicode NFKC 和空白规范化，再按原始 ID 保持成对文本同组划分。

文本训练 / 验证 / 测试分别为 **2800 / 600 / 600**，共 2000 个原始组。规范化文本指纹和组 ID 在三组之间均无交集。处理后的正文与标签位于 `data/course_20261027/processed/text/`；原始来源可沿固定版本复查。上述划分是本组在公开训练数据内建立的课程划分。

来源：[NTIRE 官方任务](https://github.com/msu-video-group/NTIRE-2026-DeepFake-Detection)、[NTIRE 数据](https://huggingface.co/datasets/deepfakesMSU/NTIRE-RobustAIGenDetection-train)、[NLPCC 官方任务](https://github.com/NLP2CT/NLPCC-2026-Task6-Detection)。

## 实验二、三：真实训练与压缩

图像模型为三层卷积 CNN，通道数 16 / 32 / 64。训练 15 轮，按验证集 macro-F1 选择权重；压缩时按卷积通道重要性保留 12 / 24 / 48 个通道，切片重建卷积、批归一化及分类头，恢复训练 6 轮。是否采用压缩模型依据验证集预设的 macro-F1 损失容差，测试集用于最后统计。

中文分类器使用字符 2–4 元 TF-IDF 与逻辑回归。完整词表上限 12000；比较 2000 / 4000 / 8000 特征，按验证集 macro-F1 下降最多 2 个百分点的规则选择最小候选。概率校准同样使用验证划分。

| 指标 | 实验二基线 | 实验三优化 |
| --- | ---: | ---: |
| CNN 参数量 | 23938 | 13634 |
| CNN 状态字典体积 | 104780 B | 62982 B |
| CNN 计算中位耗时 | 0.447 ms | 0.293 ms |
| CNN 测试准确率，80 张 | 68.75% | 66.25% |
| 中文词表特征数 | 12000 | 2000 |
| 中文模型文件体积 | 219464 B | 41160 B |
| 中文单条计算中位耗时 | 1.744 ms | 0.930 ms |
| 中文测试准确率，600 条 | 98.33% | 98.50% |

计时采用 CPU、4 线程、预热 8 次、测量 40 次；图像计时使用单张已准备张量，文本计时包含特征提取与分类。CNN 压缩降低了体积和耗时，同时带来 2.5 个百分点的测试准确率下降；课程页保留这项取舍。常规检测默认仍使用既有 DEAR / MPU 增强方案。

## 实验四：权重直接部署

- `POST /api/course/image/detect?stage=trained` 读取 `image_trained.pt`；`stage=optimized` 读取 `image_optimized.ts`。
- `POST /api/course/text/detect` 的 `stage` 为 `trained` 时读取 `text_full.joblib`，为 `optimized` 时读取 `text_compact.joblib`。
- `GET /api/course` 显示五阶段记录；前端“课程实验”可下载完整 JSON，并用课程样例进入检测页。
- 增强方案、课程训练基线、课程优化模型使用明确的选择项与模型版本。文档页继续使用增强检测和原有报告服务。

真实 HTTP 重放了全部 **80 张测试图片和 600 条测试文本**。API 分数与保存预测的绝对差在 `0.0001` 以内，0.5 阈值下的二分类结果全部一致。记录见 `http-verification.json`。

## 实验五：大模型决策、API 工具与 LoRA

模型采用 Qwen 官方 **Qwen3.5-0.8B** 的文本骨干，固定 revision `2fc06364715b967f1860aea9cf38778875588b17`。权重、配置、分词器和 Apache-2.0 许可随模型目录保存。图片分析由检测 API 执行；大模型负责理解操作需求、选择工具计划和解释工具结果。

路由数据为本轮编写的 **130 条中英文操作指令**，按不同表述分为训练 80、验证 20、测试 30。包括模型介绍、课程查询、文字、图像、文档、编辑、图文组合、图文档组合、检测与编辑组合和补充输入。它们用于教学工具路由训练，单独记录来源与划分。

实际 LoRA 设置：rank 4、alpha 8，目标层 q_proj / v_proj，共 **159744 个可训练参数**，CPU bfloat16，训练 **64 步**。损失为允许工具计划字母 token 上的交叉熵；每 16 步在验证集检查一次，按验证集选择检查点。工具计划由大模型的下一 token 分数决定，运行时只保留有实际输入可用的计划。

| 工具选择测试，30 条保留指令 | 微调前 | 微调后 |
| --- | ---: | ---: |
| 正确数 | 11 / 30 | 29 / 30 |
| 准确率 | 36.67% | 96.67% |

完整保留了那条未识别出组合编辑需求的指令及预测结果，见 `agent/finetune-metrics.json`。训练过程逐步损失、样本 ID 和耗时见 `agent/training-history.jsonl`。运行服务已从保存后的适配器重新载入，并完成实际 API 调用。

执行过程为：用户需求与可用附件 → 大模型选择计划 → 输入及工具白名单验证 → 通过 ASGI 访问现有 API 路由 → 读取返回结果 → 大模型生成答复。每次请求最多选择两项工具，并保存接口路径、HTTP 状态与耗时供界面查看。文档结果可转到文档页导出 Word / HTML / JSON；对话不写入 localStorage。

真实模型联调覆盖课程查询、文本、图文、文档、携带历史的模型查询以及英文检测与编辑组合。工具结果和模型回答分别保留，工具选择指标与图像、文本识别指标分别统计。

参考：[Qwen 官方模型](https://huggingface.co/Qwen/Qwen3.5-0.8B)、[Transformers Qwen3.5 实现说明](https://huggingface.co/docs/transformers/model_doc/qwen3_5)。

## 演示与复现

1. 打开 `/#course`，查看五阶段状态和模型对照，下载实验 JSON。
2. 点击“试用课程文本模型”，运行优化模型；在右上方切换“课程 · 训练基线”再次检测，核对版本。
3. 试用课程图像模型；切回“增强检测”可继续检查 4K 原图。
4. 打开“大模型助手”，上传正文、图片或文档，并明确希望执行的操作；检查实际 API 调用记录。
5. 使用文档工具生成报告后，点击“打开文档报告”查看原文与三种导出。

```powershell
.venv\Scripts\python.exe scripts/prepare_course_2026.py --proxy http://127.0.0.1:7897
.venv\Scripts\python.exe scripts/train_course_2026.py
.venv\Scripts\python.exe scripts/fetch_course_agent.py --proxy http://127.0.0.1:7897

.venv\Scripts\python.exe scripts/verify_course_assets.py
.venv\Scripts\python.exe scripts/verify_course_system.py --url http://127.0.0.1:8006
```

训练脚本会重新写入对应课程权重；复现时使用独立克隆目录。固定依赖沿用项目 Python 3.12 环境，未修改全局 Python。验证索引为 `results/course_20261027/verification.json`。
